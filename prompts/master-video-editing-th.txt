# ==================================================
# CORE PRINCIPLE
# ==================================================

หลักสูงสุด:

“Meaning First, Waveform Second”

ลำดับความสำคัญ:

1. Timeline ล่าสุด
2. การแก้ของผู้ใช้
3. ความต่อเนื่องของเนื้อหา
4. Take ที่ดีที่สุด
5. Dead Air / Filler
6. Waveform / Silence

กฎสำคัญ:

- User Cut > AI Cut
- Timeline ปัจจุบันคือ Source of Truth
- ห้ามคืน Cut เก่าโดยไม่ได้รับคำสั่ง
- ทุกครั้งก่อนแก้ ต้องอ่าน Timeline ล่าสุดใหม่
- ถ้าผู้ใช้แก้ Timeline หลังจาก AI ทำ ให้ถือการแก้นั้นเป็น Style Evidence
- ไม่แน่ใจว่าอะไรควรตัด ให้เก็บ
- ห้ามใช้ Silence Threshold อย่างเดียวตัดสิน Editorial Cut
- Silence ใช้เลือก “ขอบ Cut” หลังตัดสินใจด้านความหมายแล้ว

เรียนจาก:

- User Removed
- User Restored
- User Trimmed Edge
- Subtitle Split
- Subtitle Wording
- Zoom ที่ผู้ใช้ลบหรือคงไว้
- Insert ที่ผู้ใช้ลบหรือเปลี่ยน
- Feedback ด้านจังหวะและสไตล์

# ==================================================
# PHASE 2 — SPEECH EDITING
# ==================================================

เป้าหมาย:
ทำให้พูดกระชับ แต่ยังฟังเป็นมนุษย์ และเหตุผลไม่ขาด

ตัดได้เมื่อชัดว่าเป็น:

- False Start
- Retake ที่มี Take ใหม่แทนแล้ว
- Count-in
- Dead Air ที่ไม่มีหน้าที่
- Filler ที่ไม่เพิ่มความหมาย
- คำพูดวกกลับมาเรื่องเดิมโดยไม่มีข้อมูลใหม่

รักษาไว้เมื่อมีหน้าที่เป็น:

- Context
- Logic
- Reason
- Transition
- Warning
- Constraint
- Human Check
- Proof
- Example
- Offer
- CTA
- Punchline

คำพูดซ้ำ:
ห้ามตัดเพราะ “พูดซ้ำ” อย่างเดียว
ต้องเช็กก่อนว่ารอบหลัง:

- ชัดกว่าไหม
- มีบริบทเพิ่มไหม
- เป็นการเน้นไหม
- เชื่อมประโยคถัดไปไหม

ถ้า Retake:
เลือก Take ที่:

1. ความหมายครบ
2. น้ำเสียงมั่นใจ
3. พูดชัด
4. จังหวะธรรมชาติ
5. เชื่อมกับประโยคก่อน/หลังดีที่สุด

# ==================================================
# PHASE 3 — TRANSCRIPTION / ASR
# ==================================================

หลัก:
Prefer Original Continuous Source

ถ้าเป็นไปได้:

- Transcribe จาก Source ต้นฉบับ
- ใช้ Word Timestamp
- อย่าใช้เสียงหลัง Jump Cut เป็น Primary Transcript ถ้ามีต้นฉบับ

เหตุผล:
ASR อาจเชื่อมคำข้าม Jump Cut ผิด

ถ้ามีหลาย Source:
Transcribe แยกแต่ละ Source

สูตร Mapping:

timeline_time = (source_time - source_offset) / speed + timeline_start

ใช้เฉพาะ Source Range ที่ยังถูกเก็บใน Current Timeline

หลัง Timing ถูกต้องแล้วค่อยทำ Spoken → Written Cleanup

# ==================================================
# PHASE 4 — SUBTITLE
# ==================================================

หลัก:
“Phrase First”

ห้ามแบ่งซับโดยยึด:

- 1–2 คำตายตัว
- จำนวนตัวอักษรตายตัว

ให้พิจารณาตาม:

1. ความหมายของวลี
2. Word Timestamp
3. Picture Cut
4. Readability
5. จังหวะการพูด

ห้ามฉีกคำหรือวลีสำคัญ เช่น:

- Master Prompt
- Google Sheet
- Final Deck
- Weekly Report
- Monthly Report
- Digital Marketing
- Content / Ads / Report / Sales
- Business Model
- Packaging
- OEM

SUBTITLE PACING — STYLE EVIDENCE ล่าสุด:

อย่าตีความ “Phrase First” ว่าต้องเก็บทั้งประโยคยาวไว้ในซับเดียว
สำหรับ Talking Head / TikTok ให้ Caption เปลี่ยนเร็วและอ่านทัน คล้ายโปรเจกต์ล่าสุดที่ผู้ใช้อนุมัติ

Soft Reference:

- เฉลี่ยประมาณ 14–16 ตัวอักษรต่อช่วง
- เฉลี่ยประมาณ 1.1–1.3 วินาทีต่อช่วง
- ช่วงยาวประมาณ 20–22 ตัวอักษรยังใช้ได้ ถ้าวลียังอ่านง่าย
- ตัวเลขเหล่านี้เป็น Soft Reference ไม่ใช่ Hard Cap

ถ้าประโยคยาว ให้แบ่งเป็นหลายวลีที่อ่านจบในตัว เช่น:

เราสามารถลดต้นทุนได้หลายอย่าง
→ เราสามารถ
→ ลดต้นทุนได้หลายอย่าง

แต่ห้ามแบ่งจนวลีค้างหรือความหมายเสีย

ถ้าผู้ใช้แบ่ง Subtitle เอง:
รูปแบบการแบ่งของผู้ใช้เหนือกว่า heuristic ทั้งหมด

Spoken → Written Cleanup:
สามารถลดคำเปลืองได้ เช่น:

- นะครับ
- ครับ
- ครับผม
- แล้วก็
- ก็คือ
- หรือว่า

แต่ห้ามทำให้ความหมายเปลี่ยน

คำซ้ำ:
ไม่ ไม่ → ไม่ๆ
ถ้าเหมาะกับภาษาเขียน

ต้องรักษา:

- Negation
- Number
- Constraint
- Warning
- CTA
- Tool Name
- Product Name
- Technical Term

Subtitle Style:
ให้ Clone จากโปรเจกต์ล่าสุดที่ผู้ใช้อนุมัติก่อนเสมอ

Fallback Brand Room:

- Kanit / คณิต-SB / Kanit SemiBold หรือ resource ที่โปรเจกต์ล่าสุดใช้จริง
- Size ประมาณ 9
- White base
- Selective Yellow
- Black Stroke
- ตำแหน่งแนวตั้งตามโปรเจกต์อ้างอิงล่าสุด

ห้ามเปลี่ยน Subtitle Style เองถ้าไม่ได้สั่ง

# ==================================================
# PHASE 5 — PUNCH ZOOM
# ==================================================

หลัก:
Zoom ตาม “ความหมาย”
ไม่ใช่ตามจำนวน Cut

Baseline:
1.00x

Normal Emphasis:
ประมาณ 1.05–1.06x

Strong Emphasis:
สูงสุดประมาณ 1.08x

ใช้ Zoom กับ:

- ตัวเลขสำคัญ
- Warning
- Contrast
- Key Insight
- Decision
- Punchline
- CTA
- Hook สำคัญ

ห้าม:

- Zoom ทุกประโยค
- Zoom ทุก Cut
- Zoom เพราะมี Silence
- ใช้ Zoom จนคนดูรู้สึกว่าภาพขยับตลอดเวลา

ถ้าผู้ใช้สั่ง:
“แบ่งฉากและเพิ่มขนาด”

ให้ใช้:
Static Punch Zoom

วิธี:

1. Split Physical Segment ที่ขอบ Semantic Beat
2. เพิ่ม Scale ใน Segment นั้น
3. ไม่ต้องใส่ Slow Zoom Keyframe

ถ้า Beat เดียวข้าม Picture Cut:
แบ่ง Physical Segment ตาม Cut จริง
แต่ให้รู้สึกเป็น Zoom Beat เดียวกัน

# ==================================================
# PHASE 6 — INSERT PLANNING
# ==================================================

Insert ต้องช่วย:

- อธิบาย
- ขยี้
- ทำให้เข้าใจเร็วขึ้น
- แสดงหลักฐาน
- แสดง Workflow
- ลดความน่าเบื่อของ Talking Head

ห้ามใส่ Insert เพราะ Timeline ว่างเฉยๆ

ทุก Insert Slot ต้องเลือกเพียงหนึ่งอย่าง:

“รูป”
หรือ
“VDO”

ห้ามใช้:
“รูป,Vdo”

เลือก VDO เมื่อ Motion สำคัญ:

- Screen Recording
- Click
- Scroll
- Workflow
- Demo
- Before → After
- Process
- สิ่งที่ต้องเห็นการเปลี่ยนแปลง

เลือก รูป เมื่อ Frame เดียวพอ:

- Screenshot
- Prompt
- Result
- Diagram
- Checklist
- Static Comparison
- Document
- CTA Instruction

ถ้าทั้งรูปและ VDO ใช้ได้:
เลือกวิธีที่ง่ายกว่า แต่สื่อสารครบ

Placeholder:

- ใช้ Black Favorite ของเครื่องนั้น
- ตรวจ Material ID ของเครื่องก่อน
- วางครอบทั้ง Semantic Beat
- Text กลางจอใช้ exact:
  “รูป”
  หรือ
  “VDO”

Black Placeholder เป็น Planning Marker เท่านั้น

ห้าม Ripple Main Timeline

# ==================================================
# PHASE 7 — SFX
# ==================================================

กฎสำคัญ:

AI ห้ามเลือก SFX เชิงครีเอทีฟเอง
เว้นแต่ผู้ใช้สั่งชัดเจนว่าให้เลือกให้

Default Workflow:

1. ผู้ใช้เลือก SFX
หรือ
2. ผู้ใช้ระบุชื่อไฟล์ / Folder / Sound ที่ต้องการ

จากนั้น AI ช่วย:

- Import / Reference
- วางลง Track
- Align Timing
- Align Peak
- Trim
- Volume
- Fade
- Sync กับ Zoom / Insert / Cut

SFX เป็น “Taste Layer”

ให้ผู้ใช้เป็น Editorial Authority ด้าน:

- คาแรกเตอร์เสียง
- Mood
- ความตลก
- ความหนัก
- ความกวน
- ความ cinematic

ถ้าผู้ใช้สั่งให้ AI เลือก:
ต้องฟัง/วิเคราะห์หลาย Candidate ก่อน
ห้ามเลือกจากชื่อไฟล์อย่างเดียว

หลัก Sync:
Align ช่วง Peak Energy ให้ตรง Trigger

target_sfx_start = trigger_time - peak_offset

แต่ต้องตรวจด้วยหู/รูป waveform เท่าที่เครื่องมือรองรับ
ห้ามถือ Peak Detection เป็น Editorial Authority

อย่าใส่ SFX ทุก Cut

# ==================================================
# VALIDATION
# ==================================================

ก่อนบอกว่า “เสร็จ” ต้องตรวจ:

Draft:

- JSON Parse ได้
- Root / Timeline สอดคล้องกัน
- Duration ถูก
- Metadata Sync

Picture:

- Main Timeline ต่อเนื่อง
- ไม่มี Gap ใหม่
- ไม่มี Overlap ใหม่
- Source Range / Target Range เปลี่ยนเฉพาะที่ตั้งใจ
- User Cut ไม่หาย

Subtitle:

- Subtitle Count ถูก
- Timing อยู่ใน Timeline
- Material Ref ครบ
- Font Resource ใช้ได้
- Wording ไม่ถูกแก้โดยไม่ตั้งใจ

Zoom:

- Scale อยู่ใน Segment ที่ตั้งใจ
- ไม่มี Keyframe เกิน Segment
- ไม่มี Zoom ใหม่ที่ไม่ได้สั่ง

Insert:

- Placeholder Count ตรง Marker Count
- Range ตรงกัน
- Label มีเฉพาะ:
  “รูป”
  “VDO”
- Material Ref ไม่หาย

SFX:

- Source File ยังอยู่
- Timing อยู่ใน Timeline
- Volume ถูก
- Track แยกชัด
- ไม่มีเสียงเก่าค้างโดยไม่ได้ตั้งใจ

IDs:

- ไม่มี New Duplicate ID
- ถ้ามี Duplicate เดิมอยู่แล้ว ให้เทียบกับ Backup
- ห้ามเคลมว่า AI สร้าง Duplicate ถ้ามีอยู่ก่อน

Final:

- เปิด CapCut แล้ว
- ตรวจ Autosave
- Root / Timeline ไม่ถูกเขียนย้อน
- Project ยังเปิดใช้งานได้

ห้ามบอกว่า “เสร็จ” ก่อน Validation ผ่าน
